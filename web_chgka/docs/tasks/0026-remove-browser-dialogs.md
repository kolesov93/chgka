# Task 0026: отказ от браузерных диалогов

Статус: в работе.

Branch: `task/remove-browser-dialogs`.

## Цель

Убрать из runtime-интерфейса нативные `confirm`, `alert` и `prompt`, чтобы действия не блокировали вкладку и выглядели единообразно с приложением.

## Согласованный UX

- Все прежние подтверждения выполняют действие сразу: старт/сброс игры, выбор сектора, управление группами, стратегические действия ведущего, пропуск intro, Live Ops, смена режима исторической игры и выход.
- Опасные Live Ops-действия остаются визуально отделены существующей свёрнутой красной панелью восстановления; дополнительный общий слой подтверждений не добавляется.
- Исключение №10 сохраняет защиту от утечки ответа: попытка показать во время чтения или обсуждения media из секции `Ответ` открывает компактное подтверждение внутри медиаплашки. Отмена ничего не публикует; подтверждение показывает только тот media-token, для которого оно было открыто.
- Исключение №21 сохраняет объяснение отключённому игроку, но не блокирующий `alert`: игрок возвращается на `/play`, а форма входа показывает серверное сообщение или понятный fallback `Ведущий отключил вас от игры.`.
- Существующая React-модалка запросов капитана остаётся без изменений: это серверное игровое состояние, которое ведущий обязан разрешить, а не браузерный диалог.

## Технические границы

- Backend, Socket.IO events, payloads и игровые transitions не меняются.
- Для подтверждения media хранить точный pending `media_id`; смена preview/context должна отменять устаревшее подтверждение.
- Добавить чистые helpers и frontend-тесты для media guard и kicked notice.
- Добавить structural test, который не позволит вернуть `confirm`, `alert` или `prompt` в runtime `.js/.jsx` файлы frontend.

## Вне задачи

- Универсальная дизайн-система модалок, undo/toast для каждого действия и изменение backend-правил.
- Изменение модалки запросов капитана.
- Новые подтверждения для прямых destructive actions.

## Ручной smoke

1. На `/admin` и `/play` войти ведущим и группой игроков. Нажать `Начать игру`, затем на intro `Перейти к игре`: оба действия выполняются сразу, без системных окон браузера.
2. Выбрать сектор 2 кнопкой ведущего. Во время чтения выбрать изображение Пикассо из секции `Ответ` и нажать `Показать игрокам`: внутри медиаплашки появляется предупреждение, а игрок продолжает видеть стол. Нажать `Не показывать` — media не публикуется.
3. Снова запросить показ того же изображения и подтвердить `Всё равно показать`: изображение появляется у игрока. Выбрать другое preview до подтверждения и убедиться, что старое предупреждение исчезает и не может показать предыдущий файл.
4. Открыть Live Ops и выполнить одно обратимое восстановление, например отметить свободный сектор сыгранным и вернуть его в игру. Оба клика выполняются сразу без системного подтверждения; панель остаётся визуально красной и свёрнутой по умолчанию.
5. Ведущему отключить player-группу. У игрока не появляется `alert`: вкладка возвращается на форму входа с сообщением `Ведущий отключил вас от игры.` (или точным серверным текстом). После нового входа сообщение исчезает.
6. Нажать `Выйти` у ведущего или игрока: выход выполняется сразу без системного подтверждения и возвращает текущий entrypoint на его форму входа.
