# Формат пака вопросов

Пак — локальный каталог с 13 игровыми секторами. Перед запуском backend его нужно проверить тем же parser, который загружает вопросы в игру.

## Проверка пака

Из каталога `web_chgka/backend`:

```bash
python -m validate_pack /path/to/pack
```

Для корректного sample pack команда выводит:

```text
VALID: /absolute/path/to/pack
Questions: 13 (normal: 11, blitz: 1, superblitz: 1)
Parts: 6
Media: 9 (image: 5, audio: 2, video: 2)
```

Exit codes:

- `0` — пак корректен;
- `1` — путь или содержимое пака некорректны; причина выводится в stderr без traceback;
- `2` — команда вызвана без обязательного пути или с неверными аргументами.

## Структура каталогов

В корне обязательны каталоги `01`–`13`, по одному на сектор:

```text
pack/
├── 01/
│   └── question.md
├── 02/
│   ├── question.md
│   └── media/
│       └── image.jpg
├── ...
└── 13/
    └── question.md
```

Дополнительные двухзначные цифровые каталоги, например `00` или `14`, запрещены. Именованные вспомогательные каталоги в корне допустимы и не считаются игровыми секторами.

## Frontmatter и секции

Каждый `question.md` начинается с простого frontmatter. Поддерживаются только скалярные строки `key: value`, без YAML-списков и вложенных объектов:

```markdown
---
title: Название вопроса
type: normal
author: Имя автора
---

# Вопрос

Текст вопроса.

# Ответ

Текст ответа.

# Комментарий

Необязательный комментарий.

# Источник

Необязательный источник.
```

Поля:

- `title` — обязательно;
- `type` — `normal`, `blitz` или `superblitz`; если отсутствует, используется `normal`;
- `author` — необязательно.

Другие frontmatter-поля сейчас не используются приложением. Заголовки секций должны быть H1 и идти в порядке `Вопрос` → `Ответ` → `Комментарий` → `Источник`.

Для `normal` обязательны `Вопрос` и `Ответ`; подпапки `01`–`03` запрещены. Для `blitz` и `superblitz`:

- верхний `question.md` содержит общий `Вопрос`, но не `Ответ`;
- рядом обязательны ровно три каталога `01`, `02`, `03`;
- каждая часть имеет `type: normal`, собственные `Вопрос` и `Ответ` и не может содержать вложенные части.

## Медиа

Медиа кладутся в каталог `media/` рядом с соответствующим `question.md` и подключаются Markdown-ссылкой:

```markdown
![Картина](media/painting.jpg)
![audio](media/melody.mp3)
![video](media/clip.mp4)
```

Поддерживаемые расширения:

- изображения: `.jpg`, `.jpeg`, `.png`;
- аудио: `.mp3`, `.wav`, `.ogg`;
- видео: `.mp4`, `.webm`.

Локальный путь обязан начинаться с `media/` и после разрешения `..` и symlink оставаться внутри каталога текущего вопроса или части. Абсолютные пути и выход наружу запрещены. Каждый упомянутый файл должен существовать, а каждый файл внутри `media/` должен быть использован в Markdown. Внешние URL с `://` остаются обычными Markdown-ссылками и не считаются локальным медиа пака.

## Ограничения доверия

Markdown сейчас конвертируется с разрешённым raw HTML. Проверка структуры не делает HTML безопасным: до отдельной security-задачи следует использовать только доверенные паки.
