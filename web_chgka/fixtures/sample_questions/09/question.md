# Вопрос

Этот американский писатель известен под псевдонимом Марк Твен. Его настоящее имя — Сэмюэл.

Назовите его фамилию.

# Ответ

**Клеменс** (Сэмюэл Лэнгхорн Клеменс)

# Комментарий

Псевдоним «Марк Твен» происходит от термина речников на Миссисипи: «mark twain» означает «метка два» — безопасная глубина для прохода судна.

# Источник

- Ron Powers, "Mark Twain: A Life"
